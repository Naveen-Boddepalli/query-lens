QueryLens is a self-built toy relational database engine that runs entirely in your browser. Type a
query, press Run, and step through exactly what happens to it — Parser → Planner → Optimizer →
Execution → Buffer Pool → B+Tree Index → Locks → Result — one event at a time, with the state of
every stage on screen at once.

It is a learning tool, not a production database. Every number it shows is true to *this* engine —
not to the exact behaviour of Postgres, MySQL, or any real system. See the [FAQ](/faq/) for exactly
where the model simplifies and why.

<CardGrid>
  <Card title="The buffer pool" icon="document">
    Eight fixed frames, a real eviction policy (LRU or clock sweep), hits and misses you can watch
    happen. [Read the concept](/concepts/buffer-pool/).
  </Card>
  <Card title="The B+Tree index" icon="seti:db">
    A real B+Tree — insert, split, point lookup — with the descent traced node by node.
    [Read the concept](/concepts/btree/).
  </Card>
  <Card title="Predict, then reveal" icon="magnifier">
    At marked steps the app asks you to commit to an answer — which frame gets evicted? which child
    pointer? — before it shows you. The prompts are what make it stick.
  </Card>
  <Card title="No accounts, no telemetry" icon="approve-check">
    Nothing leaves your browser. The engine runs client-side; a shared link carries the query and
    step in the URL, not on a server.
  </Card>
</CardGrid>
