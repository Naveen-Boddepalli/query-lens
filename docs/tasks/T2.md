# Task Contract: T2 — Navigation, Layout Shell & Global Chrome

## Objective
Redesign the application layout shell (`TopNav`, `Footer`, `Layout`, `Logo`, `PageHeader`) with a modern glassmorphic top navigation bar, responsive mobile menu drawer, active route indicators, and an organized footer layout.

## Scope
- `src/ui/TopNav.tsx`
- `src/ui/Footer.tsx`
- `src/ui/Layout.tsx`
- `src/ui/Logo.tsx`
- `src/ui/PageHeader.tsx`

## Depends On
- `T1`

## Design Specifications (Stitch Tactile Glass)
- **Reference**: Stitch project `QueryLens - Tactile Glass Studio` (`12661379354391736788`), Screen `fe971626ee3e42fe8ac3b64da530e561` & `2e4d245b39c64f2285a4c30076337bce`.
- **Zero Emojis Directive**: Strictly zero emojis in headers, links, badges, or buttons. Use crisp monochrome inline SVG line icons and monospace technical typography.
- **TopNav Glass Chrome**:
  - Sticky frosted header (`ql-glass-header` / `backdrop-blur-md` with `border-b border-edge bg-surface/85`).
  - Sleek geometric SVG database logo in `Logo.tsx` with mono version tag `v0.9.4-dev`.
  - Active route indicator with tactile pill styling (`border-accent/40 bg-accent-soft text-ink shadow-neu-rest`).
  - Client-side in-memory engine status badge with tiny green pulse indicator dot (`Engine: In-Memory WASM`).
  - GitHub icon link with vector SVG star counter (`4.2k`), and ThemeToggle integration.
- **Footer Structure**:
  - Translucent glass footer (`border-t border-edge bg-surface-2/60 backdrop-blur-sm`).
  - Four clean columns: Primary Navigation, Database Sandboxes, Learning & Verification, Engine & Meta.
  - Quiet technical footer bar: MIT License, '100% Client-Side In-Memory Engine', link to repository.
- **PageHeader Component**:
  - Polished breadcrumb, title with subtle gradient/sheen, blurb, and right-aligned action toolbar slot.

## Deliverable
1. Sleek sticky header with `backdrop-blur`, refined brand wordmark/logo, active pill indicators, and accessible mobile hamburger drawer.
2. Grouped footer with clear columns (Navigation, Standalone Tools, Learning & Docs, Meta) and engine status badge.
3. Reusable, polished `PageHeader` component for page titles, eyebrow categories, and action toolbars.
