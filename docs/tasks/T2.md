# Task Contract: T2 — Navigation, Layout Shell & Global Chrome

## Objective
Redesign the application layout shell (`TopNav`, `Footer`, `Layout`, `Logo`, `PageHeader`) with a modern glassmorphic top navigation bar, responsive mobile menu drawer, active route indicators, and an organized footer layout.

## Scope
- `src/ui/TopNav.tsx`
- `src/ui/Footer.tsx`
- `src/ui/Layout.tsx`
- `src/ui/Logo.tsx`
- `src/ui/PageHeader.tsx`

## Depends On
- `T1`

## Constraints
- Do NOT touch `src/engine/**` or modify `NAV_ITEMS` in `src/routes.ts`.
- Navigation must remain 100% accessible via keyboard (`Tab`, `Enter`, visible focus rings).
- Mobile viewports (360px - 768px) must not exhibit horizontal overflow.

## Deliverable
1. Sleek sticky header with `backdrop-blur`, refined brand wordmark/logo, active pill indicators, and mobile hamburger drawer.
2. Grouped footer with clear columns (Navigation, Standalone Tools, Learning & Docs, Meta) and status indicator.
3. Reusable, polished `PageHeader` component for page titles, eyebrow categories, and action toolbars.

## Gate
```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm budget && pnpm test:cli
```
