# Task Contract: T6 — Standalone Tools Suite & Sandboxes

## Objective
Unify and redesign the UI for all 9 standalone database sandboxes under `/tools` and the `/tools` index directory.

## Scope
- `src/pages/tools/**`
- `src/pages/ToolsIndexPage.tsx`

## Depends On
- `T2`

## Constraints
- Do NOT touch `src/engine/**` or modify simulator physics/algorithms.
- Ensure all interactive inputs (policy dropdowns, key inserts, frame counts) respond quickly and cleanly.

## Deliverable
1. Tools directory page (`ToolsIndexPage`) featuring categorized cards with badges and difficulty/topic tags.
2. Consistent header, control toolbar, and metrics strip across all 9 tools:
   - Buffer Pool Sandbox (`BufferPoolToolPage.tsx`)
   - B+Tree Visualizer (`BTreeToolPage.tsx`)
   - Slotted Page memory visualizer (`PageToolPage.tsx`)
   - External Merge Sort visualizer (`SortToolPage.tsx`)
   - Planner & Optimizer sandbox (`PlannerToolPage.tsx`)
   - Lock Manager simulator (`LocksToolPage.tsx`)
   - Hash Join simulator (`HashJoinToolPage.tsx`)
   - SQL Grammar explorer (`GrammarToolPage.tsx`)
   - Recursive-Descent Parser sandbox (`ParserToolPage.tsx`)

## Gate
```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm budget && pnpm test:cli
```
