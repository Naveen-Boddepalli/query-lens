# Task Contract: T9 — Documentation, Settings & Utility Views

## Objective
Polish the MDX documentation system (`/docs/*`), Pipeline Stages reference (`/stages/*`), User Settings (`/settings`), Assignment builder (`/assignments/new`), Trace inspector (`/trace`), and 404 page.

## Scope
- `src/ui/DocsLayout.tsx`
- `src/ui/DocsComponents.tsx`
- `src/ui/Sidebar.tsx`
- `src/ui/StagesLayout.tsx`
- `src/pages/StagesIndex.tsx`
- `src/pages/StagePage.tsx`
- `src/pages/SettingsPage.tsx`
- `src/pages/TracePage.tsx`
- `src/pages/AssignmentsNewPage.tsx`
- `src/pages/NotFoundPage.tsx`

## Depends On
- `T2`

## Constraints
- Do NOT touch `src/engine/**` or any MDX content in `src/pages/DocsContent/**`.
- Maintain full keyboard accessibility and axe-clean compliance.

## Deliverable
1. Docs layout with responsive sticky sidebar navigation, breadcrumbs, on-this-page table of contents, and rich callout blocks.
2. Stages explorer with visual stage index and deep-dive detail views.
3. User settings screen with clear segmented preferences for theme, default buffer policy, prediction mode, and animation speed.
4. Clean Assignment authoring tool with instant preview link generator.
5. Trace event log inspector with collapsible JSON nodes and search filter.
6. Friendly 404 error screen with search suggestions and back-home CTA.
