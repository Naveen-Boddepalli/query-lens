# Task Contract: R1 — Design Research: Glassmorphism & Neumorphism for DevTools

## Objective
Conduct in-depth design research on blending Glassmorphism and Neumorphism for developer dashboards and technical tools. Produce actionable styling tokens, CSS recipes, accessibility rules, and contrast benchmarks for both dark and light modes.

## Scope
- `docs/research/glass-neumorphic-system.md`

## Depends On
- none

## Constraints
- Do NOT touch `src/**` or any project code.
- Must preserve WCAG AA contrast standards (minimum 4.5:1 text, 3:1 controls).
- Keep file self-contained under `docs/research/`.

## Deliverable
A comprehensive design report in `docs/research/glass-neumorphic-system.md` containing:
1. Exact CSS / Tailwind recipes for glassmorphic containers (blur, opacity, sub-pixel borders, inner hairline sheen).
2. Exact CSS recipes for tactile neumorphic controls (extruded resting shadows, inset pressed debossing) across dark and light modes.
3. Performance analysis (GPU backdrop-filter optimization, avoiding layer thrash).
4. Accessibility guidelines for maintaining crisp code syntax highlighting on translucent surfaces.

pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm budget && pnpm test:cli
