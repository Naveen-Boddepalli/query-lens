# Task Contract: R2 — Design Research: Database Internals Visualizers & High-Density UI

## Objective
Analyze state-of-the-art database internal visualizers (BusTub, VisuAlgo, SQLite tools, Neon, PlanetScale, explain.dalibo) to extract best practices for high-density diagramming, B+Tree graphs, Buffer Pool frame grids, and execution timeline scrubbers.

## Scope
- `docs/research/database-internals-ui.md`

## Depends On
- none

## Constraints
- Do NOT touch `src/**` or any project code.
- Focus specifically on the 8 pipeline stages present in QueryLens (Parser, Planner, Optimizer, Executor, Buffer Pool, B+Tree, Lock Manager, Result).

## Deliverable
A structured research report in `docs/research/database-internals-ui.md` containing:
1. Visual architecture patterns for B+Tree index traversal (crabbing indicator, leaf doubly-linked lists, internal vs leaf node differentiation).
2. Buffer Pool memory layout conventions (slot grids, dirty/clean status, clock-sweep hand visualization, hit/miss metrics).
3. Volcano iterator tree visualization patterns (operator badges, cost metrics, row count flows).
4. Timeline scrubber ergonomics for stepping through hundreds of database execution events without visual fatigue.
