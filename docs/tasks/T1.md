# Task Contract: T1 — Design Tokens, Typography & Primitive Controls

## Objective
Elevate the core design system tokens in `src/index.css` and shared UI primitives in `src/ui/primitives.ts` using the Stitch-inspired base design: professional, classic developer-tool UI combining frosted glassmorphism (`backdrop-filter: blur`, translucent layered surfaces) and subtle neumorphic depth (soft dual-layer shadow + crisp inner hairline sheen) in both dark and light themes, without over-animation.

## Scope
- `src/index.css`
- `src/ui/primitives.ts`
- `src/ui/theme.ts`
- `src/ui/ThemeContext.tsx`
- `src/ui/ThemeToggle.tsx`

## Design Specifications (Stitch Base Synthesis)
- **Reference**: Detailed token specifications and OKLCH recipes are documented in `docs/research/glass-neumorphic-system.md`. Stitch Project `QueryLens - Tactile Glass Studio` (`12661379354391736788`).
- **Zero Emojis Directive**: Strictly zero emojis anywhere in CSS pseudo-elements, button text, or token labels. Use clean monochrome SVG lines and technical typography only.
- **Glassmorphic Surfacing**:
  - Translucent surfaces (`bg-surface-2/75` with `backdrop-blur-md` on panels and chrome).
  - 1px crisp sub-pixel border outline combined with subtle inner top hairline sheen (`--color-hairline`).
- **Soft Neumorphic Depth**:
  - Dark Theme: Deep obsidian canvas (`oklch(0.14 0.015 260)`), elevated panels with dual shadow (tight contact shadow + soft ambient diffuse shadow), subtle inset highlight.
  - Light Theme: Clean slate/alabaster canvas (`oklch(0.98 0.005 260)`), soft dual-shadow elevation (`shadow-e1..e3`), high-contrast dark text and borders.
- **Motion & Interaction**:
  - Restrained, classic, professional micro-interactions only (`150ms ease-out`). No bouncing or excessive animations.
  - Tactile button press (`active:scale-[0.99]` or `active:translate-y-px`).
- **Color Accents & Telemetry**:
  - Primary Accent: Precision Cyan / Sapphire (`oklch(0.76 0.16 215)`).
  - Functional Semantics: Hit/Commit (Emerald `oklch(0.78 0.16 155)`), Miss/Contend (Amber `oklch(0.80 0.16 75)`), Evict/Conflict (Rose `oklch(0.70 0.20 25)`).

## Constraints
- Do NOT touch `src/engine/**` or any backend execution logic.
- Touch ONLY files in scope: `src/index.css`, `src/ui/primitives.ts`, `src/ui/theme.ts`, `src/ui/ThemeContext.tsx`, `src/ui/ThemeToggle.tsx`.
- Preserve all existing CSS variable names and utility token exports so downstream components remain functional.
- Ensure WCAG AA contrast (minimum 4.5:1 for body text, 3:1 for large/interactive elements) in both dark and light modes.
- Bundle budget must remain green (`pnpm budget`).

## Deliverable
1. Refined CSS design tokens in `src/index.css` providing glassmorphism and soft neumorphic elevation across both dark and light themes.
2. Polished button variants (`btnPrimary`, `btnSecondary`, `btnGhost`), interactive cards (`card`, `cardInteractive`), inputs (`inputField`), and segmented radio controls (`segBase`, `segOn`, `segOff`) with tactile active press animations.
3. Contrast-checked light theme tokens for zero visual regression in light mode.
