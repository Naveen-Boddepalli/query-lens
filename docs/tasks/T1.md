# Task Contract: T1 — Design Tokens, Typography & Primitive Controls

## Objective
Elevate the core design system tokens in `src/index.css` and shared UI primitives in `src/ui/primitives.ts` to establish an ultra-clean, modern developer-tool aesthetic ("Obsidian & Electric Sapphire") with high contrast, tactile surfaces, and seamless dark/light modes.

## Scope
- `src/index.css`
- `src/ui/primitives.ts`
- `src/ui/theme.ts`
- `src/ui/ThemeContext.tsx`
- `src/ui/ThemeToggle.tsx`

## Constraints
- Do NOT touch `src/engine/**` or any backend execution logic.
- Preserve all existing CSS variable names and utility token exports so downstream components remain functional.
- Ensure WCAG AA contrast (minimum 4.5:1 for body text, 3:1 for large/interactive elements) in both dark and light modes.
- Bundle budget must remain green (`pnpm budget`).

## Deliverable
1. Refined OKLCH surface ramp with subtle top-border sheen (`ql-sheen`), sub-pixel borders (`--color-edge`), and glowing active indicators.
2. Polished button variants (`btnPrimary`, `btnSecondary`, `btnGhost`), interactive cards (`card`, `cardInteractive`), inputs (`inputField`), and segmented radio controls (`segBase`, `segOn`, `segOff`) with tactile active press animations.
3. Contrast-checked light theme tokens for zero visual regression in light mode.

## Gate
```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm budget && pnpm test:cli
```
